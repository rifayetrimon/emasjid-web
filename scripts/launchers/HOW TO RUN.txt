================================================
  HOW TO RUN — eMasjid Web
================================================

You DON'T need to run any commands. Just follow
the steps for your computer.

------------------------------------------------
  STEP 1 — Install Node.js (one time only)
------------------------------------------------

Open this link in your browser:

    https://nodejs.org/

Download the green "LTS" button. Run the installer
and click Next → Next → Finish. That's it — you
only do this once on a new computer.

------------------------------------------------
  STEP 2 — Start the website
------------------------------------------------

On a Mac:
    Double-click  "Start Server.command"

On Windows:
    Double-click  "Start Server.bat"

On Linux:
    Right-click "Start Server.sh" → Run as program
    (or open a terminal and run ./Start\ Server.sh)

A black window will open showing some text. Leave
it open — closing it stops the website.

------------------------------------------------
  STEP 3 — Open the website
------------------------------------------------

Your browser will open automatically after a few
seconds at:

    http://localhost:3000

If it doesn't open by itself, type that address
into Chrome/Safari/Edge yourself.

------------------------------------------------
  How to STOP the website
------------------------------------------------

Close the black window that opened in Step 2.

------------------------------------------------
  Mac users — "cannot be opened because it is
  from an unidentified developer"
------------------------------------------------

If macOS blocks the .command file the first time:

    1. Right-click  "Start Server.command"
    2. Choose  "Open"
    3. Click  "Open"  in the dialog that appears

You only need to do this the first time.
